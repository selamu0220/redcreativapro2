# 📋 Master Checklist: Curso Completo de SEO (0 a 100)

Este documento desglosa el video en 100 acciones y conceptos ejecutables, organizados desde lo esencial hasta lo avanzado y técnico.

## 🚨 Nivel 1: Fundamentos Críticos y Configuración (La Base)
*Lo que debes entender y configurar antes de escribir una sola palabra.*

- [x] 1. Definir el objetivo: Decidir si vas a rankear sitios para clientes (Client SEO) o sitios propios para vender leads/afiliación (Lead Gen).
- [x] 2. Entender el "Juego": Asimilar que el SEO es de "bajo mantenimiento" a largo plazo comparado con los anuncios pagados (Ads).
- [x] 3. Las 4 Llaves del SEO: Memorizar los pilares: Relevancia de Página, Autoridad de Dominio, Autoridad de Enlace y Relevancia de Enlace.
- [ ] 4. Selección de Dominio (EMD): Considerar un Exact Match Domain (ej. plomeronuevayork.com) para un impulso inicial en el ranking.
- [ ] 5. Selección de Dominio (Marca): Considerar un Branded Domain (ej. PlomerosSmith.com) para mayor confianza y flexibilidad a largo plazo.
- [x] 6. No rankear la Home: Entender que la página de inicio es la "puerta de entrada", las páginas internas son las que se posicionan para keywords específicas.
- [x] 7. Comprar Dominio: Adquirir el dominio en un registrador confiable.
- [x] 8. Comprar Hosting: Adquirir un plan de hosting (Vercel en este caso).
- [ ] 9. Usar cupones: Aplicar extensiones como "Honey" al comprar para reducir costos iniciales.
- [x] 10. Conectar DNS: Configurar los nameservers del dominio para que apunten al hosting.
- [x] 11. Instalar WordPress: (Equivalente: **Next.js Project** configurado).
- [x] 12. Limpieza inicial: Eliminar plugins y temas basura (Clean Code).
- [x] 13. Instalar Tema: (Equivalente: **Tailwind/Custom Design** implementado).
- [x] 14. Instalar Yoast SEO: (Equivalente: **Next.js Metadata API** implementado).
- [x] 15. Configurar Permalinks: Ajustar la estructura de URL.
- [x] 16. Certificado SSL: Asegurar que el sitio cargue con https://.
- [x] 17. Crear Página de Contacto: Obligatorio para dar señales de confianza a Google.
- [x] 18. Crear Términos y Privacidad: Páginas legales necesarias para parecer un negocio legítimo.
- [x] 19. Verificar Indexación: Comprobar que el sitio no tenga activada la opción "Disuadir a los motores de búsqueda".
- [x] 20. Entender Link Juice: Visualizar los enlaces como un líquido que fluye desde sitios externos a tu home y luego a páginas internas.
- [x] 21. Diferenciar DoFollow/NoFollow: Entender que DoFollow pasa autoridad y NoFollow (redes sociales, Wikipedia) pasa tráfico y naturalidad.
- [x] 22. Evitar la "Home Solitaria": Planificar que la Home enlace a las páginas internas para distribuir la fuerza.
- [x] 23. White Hat vs Black Hat: Conocer la diferencia y decidir tu tolerancia al riesgo.
- [x] 24. Mentalidad de Contenido: Aceptar que sin contenido de calidad, los usuarios rebotan y Google te baja el ranking.
- [x] 25. Preparar Presupuesto/Tiempo: Decidir qué tareas harás tú y cuáles externalizarás.

## 🔨 Nivel 2: Estrategia de Contenido y On-Page (El Corazón)
*Optimización interna y creación de lo que Google va a leer.*

- [x] 26. Keyword Research: Usar herramientas como Ubersuggest para encontrar palabras clave.
- [ ] 27. Estrategia de "Fruta al alcance": Buscar keywords de bajo volumen y baja competencia en lugar de una sola keyword difícil.
- [ ] 28. Sumar volúmenes: Entender que 10 keywords de 50 búsquedas = 1 keyword de 500 búsquedas, pero más fácil de rankear.
- [ ] 29. Filtrar lista: Exportar CSV y eliminar keywords irrelevantes.
- [ ] 30. Google Suggest: Mirar al pie de página de Google para encontrar keywords "Búsquedas relacionadas".
- [x] 31. Crear Títulos H1: Incluir la palabra clave principal en el H1.
- [x] 32. Optimizar H2 y H3: Usar variantes Long Tail en los subtítulos.
- [x] 33. Densidad de Keywords: Esparcir la keyword de forma natural.
- [x] 34. Contenido Largo: Escribir artículos detallados cubriendo múltiples tópicos.
- [ ] 35. Topic Clusters: Hablar de temas relacionados en la misma página.
- [x] 36. Multimedia: Incluir imágenes relevantes en cada artículo.
- [ ] 37. Video Embeds: Insertar videos de YouTube para aumentar el tiempo de permanencia.
- [x] 38. Alt Text: Rellenar el texto alternativo de las imágenes.
- [x] 39. Meta Título: Escribir un título atractivo para el buscador (CTR).
- [x] 40. Meta Descripción: Redactar una descripción que invite al clic.
- [x] 41. URL Slug: Mantener la URL corta y con la palabra clave.
- [x] 42. Enlaces Internos (Interlinking): Enlazar desde la Home a las páginas de servicio/artículos.
- [ ] 43. Enlaces Internos Contextuales: Enlazar entre artículos relacionados dentro del texto.
- [x] 44. Enlaces Externos: Enlazar a sitios de autoridad para dar contexto y validez.
- [x] 45. Reducir Rebote: Estructurar el contenido con viñetas, negritas y párrafos cortos.
- [x] 46. Optimización Móvil: Verificar visualmente que el sitio se vea perfecto en el celular.
- [x] 47. Velocidad de Página: Asegurar que las imágenes no sean pesadas.
- [ ] 48. Diversidad de Temas: Cubrir todo el campo semántico de tu nicho.
- [ ] 49. Actualización: Planificar revisar el contenido periódicamente.
- [x] 50. Configuración de Menús: Crear un menú de navegación claro y lógico.

## 🚀 Nivel 3: Link Building y Autoridad (El Motor)
*Estrategias para conseguir que otros sitios enlacen al tuyo.*

- [ ] 51. Perfil de Anchor Text (Regla de Oro): Mantener 70% de Anchor Text de Marca o URL desnuda.
- [ ] 52. Anchor Text Exacto: Usar la palabra clave exacta en menos del 1% de los enlaces.
- [ ] 53. Anchor Text Genérico: Usar "clic aquí", "visitar web" para naturalidad.
- [ ] 54. Foundation Links: Crear los primeros enlaces en perfiles sociales y directorios gratuitos.
- [ ] 55. Social Signals: Conseguir Likes/Shares en Facebook/Twitter.
- [ ] 56. Comentarios en Blogs: Dejar comentarios valiosos en blogs del nicho.
- [ ] 57. Web 2.0s: Crear blogs gratuitos y publicar contenido que enlace a tu sitio.
- [ ] 58. Guest Posting: Contactar dueños de sitios para escribir un artículo invitado.
- [ ] 59. Enlaces de Video: Subir videos a YouTube/Vimeo y poner el enlace en la descripción.
- [ ] 60. Enlaces de Audio: Usar SoundCloud para subir audios y dejar enlace.
- [ ] 61. Enlaces de Imagen: Usar Flickr, Pinterest o Imgur.
- [ ] 62. Enlaces de Documentos: Subir PDFs a sitios de compartir documentos.
- [ ] 63. Enlaces .EDU/.GOV: Si es posible, conseguir enlaces de instituciones educativas o gobierno.
- [ ] 64. Infografías: Usar Canva para crear infografías útiles.
- [ ] 65. Promoción de Infografías: Ofrecer la infografía a otros blogs.
- [ ] 66. Notas de Prensa (Press Release): Usar servicios de sindicación.
- [ ] 67. Google Entity Stacking: Crear una red de propiedades de Google interconectadas.
- [ ] 68. Google Sites: Crear un Google Site gratuito.
- [ ] 69. Tiered Link Building: Construir enlaces hacia tus enlaces.
- [ ] 70. Potenciar Tier 1: Enviar enlaces de menor calidad a tus Guest Posts.
- [ ] 71. Outsourcing: Usar plataformas para comprar foundation links.
- [ ] 72. Verificar Enlaces: Comprobar periódicamente que los enlaces siguen activos.
- [ ] 73. Diversidad de IPs: Intentar que no todas las propiedades vengan de la misma IP.
- [ ] 74. Relevancia de Enlace: Preferir un enlace de un sitio de tu temática.
- [ ] 75. Transferencia de Autoridad: Recordar que incluso enlaces no relevantes pasan fuerza.

## 🛡️ Nivel 4: Técnicas Avanzadas, PBNs y Seguridad (Escalado)
*Tácticas de alto poder y riesgo que requieren cuidado extremo.*

- [ ] 76. PBN (Red de Blogs Privada): Entender que es una red de sitios que tú controlas.
- [ ] 77. Dominios Expirados: Comprar dominios antiguos con autoridad previa.
- [ ] 78. Hosting de PBN: NUNCA usar "SEO Hosting".
- [ ] 79. IPs Clase C: Asegurar que cada sitio de la PBN tenga una IP Clase C única.
- [ ] 80. Diseño de PBN: Hacer que cada sitio se vea legítimo.
- [ ] 81. Contenido de PBN: No usar contenido copiado basura.
- [ ] 82. Cero Interlinking: JAMÁS enlazar los sitios de tu PBN entre sí.
- [ ] 83. Enlaces de Salida: Enlazar a tu sitio y a sitios de autoridad.
- [ ] 84. Bloqueo de Bots: No bloquear bots de Google en la PBN.
- [ ] 85. Gestión de Huellas: Usar diferentes temas y plugins.
- [ ] 86. Herramientas Automáticas (GSA): Usar software solo para Tier 2 o Tier 3.
- [ ] 87. GSA para Indexar: Forzar la indexación de enlaces rebeldes.
- [ ] 88. Penalización Panda: Evitar contenido duplicado y "thin content".
- [ ] 89. Penalización Penguin: Evitar sobre-optimización de Anchor Text.
- [ ] 90. Acciones Manuales: Análisis humano de Google por abusos.
- [ ] 91. Desautorizar Enlaces (Disavow): Rechazar enlaces tóxicos.
- [ ] 92. Recuperación: Auditar enlaces y solicitar reconsideración.
- [ ] 93. Diversificación de Tráfico: No depender 100% de Google.
- [ ] 94. Análisis de Competencia: Replicar los enlaces de los competidores.
- [ ] 95. Velocidad de Enlazado: Aumentar la velocidad progresivamente.
- [ ] 96. Enlaces de Home: Buscar enlaces que vayan a la Home de tu PBN.
- [ ] 97. Mantenimiento de PBN: Actualizar los sitios de la red ocasionalmente.
- [ ] 98. Uso de Ads en PBN: Colocar banners para simular intención comercial.
- [ ] 99. Paciencia (Sandbox): Entender que los sitios nuevos tardan en rankear.
- [ ] 100. Consistencia: Aplicar los fundamentos consistentemente.
