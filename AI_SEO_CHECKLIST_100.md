# 🤖 Master Checklist: Curso de AI SEO (0 a 100)

Este documento transforma la estrategia de "AI First" del video en acciones concretas, desde el cambio de mentalidad hasta la automatización y adquisición de clientes.

## 🧠 Nivel 1: Mentalidad y Fundamentos del AI SEO (La Base)
*Comprender cómo la IA cambia el juego y preparar el terreno.*

- [x] 1. Adoptar la "Analogía de la Escalera": Visualizar el SEO como una escalera donde la meta es el dinero; la IA te permite saltar los escalones manuales para llegar a la cima más rápido.
- [x] 2. IA como Herramienta: Dejar de ver la IA como un reemplazo y verla como una "llave inglesa" para aumentar tu output.
- [x] 3. Aceptar el SEO Escrito: Entender que el SEO escrito no va a desaparecer porque la gente nunca dejará de leer.
- [ ] 4. Diversificar Motores de Búsqueda: No solo pensar en Google. Considerar TikTok, YouTube, Amazon y Pinterest.
- [x] 5. Postura de Google sobre IA: Asimilar que a Google no le importa quién escribe el contenido, siempre que sea útil.
- [x] 6. Diferenciar de Spun Content: Entender que el contenido de IA no es "contenido espineado", sino contenido nuevo generado con acceso global.
- [x] 7. Evitar Contenido Duplicado: No copiar y pegar simplemente; el contenido debe aportar valor único.
- [x] 8. El factor "Barrera de Entrada": Reconocer que la ventaja competitiva será la calidad y el volumen estratégico.
- [ ] 9. Identificar Nichos Rentables: Buscar industrias con alto valor por cliente (Cirujanos, Abogados, etc.).
- [x] 10. Enfoque "AI First": Priorizar el uso de IA desde el inicio para investigación, redacción y optimización.
- [x] 11. Comprender la Intención del Usuario: Diferenciar entre buscar información vs intención de compra.
- [x] 12. Objetivo de Tráfico: Enfocarse en Buyer Intent Keywords más que en volumen de tráfico vanidoso.
- [x] 13. Definir el CMS: Plataforma elegida (Next.js en este caso).
- [x] 14. Configurar Search Console: Sitio conectado para indexación y monitoreo.
- [x] 15. Configurar Analytics: Sistema para medir tráfico y conversiones (GA4/Vercel Analytics).
- [x] 16. Planificación de Volumen: Decidir cuántos artículos se publicarán al día/semana.
- [x] 17. Estrategia Internacional: Traducir contenido a idiomas con menos competencia (Ya tenemos i18n configurado).
- [ ] 18. Revisión de Competencia: Mirar si los competidores ya están usando IA.
- [x] 19. Presupuesto de Herramientas: Asignar presupuesto para herramientas de IA (OpenAI/Anthropic API).
- [x] 20. Mentalidad de Prueba: Estar dispuesto a probar, fallar y ajustar.

## ⚡ Nivel 2: Producción y Automatización de Contenido (La Ejecución)
*Uso táctico de la IA para crear contenido masivo y optimizado.*

- [x] 21. Keyword Research con IA: Usar herramientas para encontrar keywords de baja dificultad.
- [x] 22. Clusters de Contenido: Agrupar palabras clave por temáticas (Topical Authority).
- [x] 23. Prompts Estructurados: Crear prompts detallados que pidan tablas, listas y tono específico.
- [x] 24. Uso de Journalist AI (o similar): Automatizar el flujo de creación (Script propio de blog).
- [x] 25. Generación de Títulos: Crear títulos atractivos optimizados para CTR.
- [x] 26. Estructura Visual: Asegurar párrafos cortos y legibilidad.
- [x] 27. Imágenes Destacadas (Featured Images): Generar imágenes únicas con IA.
- [x] 28. Imágenes en el Artículo: Insertar imágenes relevantes dentro del cuerpo.
- [ ] 29. Embeds de Video: Buscar e insertar videos de YouTube relevantes.
- [x] 30. Tablas de Contenido: Incluir siempre un índice al inicio.
- [x] 31. Listas y Viñetas: Formatear la información clave en bullet points.
- [x] 32. Tablas de Datos: Resumir datos complejos en tablas comparativas.
- [x] 33. Citas y Frases Destacadas: Incluir bloques de citas para resaltar ideas.
- [x] 34. Enlaces Internos Automáticos: Configurar interlinking relevante.
- [x] 35. Enlaces Externos de Autoridad: Enlazar a fuentes confiables.
- [x] 36. Densidad de Enlaces: Ajustar la frecuencia de enlaces para naturalidad.
- [x] 37. Optimización de Metadatos: Generar Meta Title y Description optimizados.
- [ ] 38. Sindicación en Redes Sociales: Automatizar publicación en Facebook, LinkedIn, Twitter.
- [x] 39. Traducción de Contenido: Clonar sitio en otros idiomas automáticamente.
- [ ] 40. Actualización de Contenido Antiguo: Usar IA para refrescar posts viejos.
- [x] 41. FAQs: Incluir sección de Preguntas Frecuentes al final (Rich Snippets).
- [x] 42. Conclusiones Claras: Terminar con resumen y CTA.
- [x] 43. Tono de Voz de Marca: Entrenar a la IA con los "Brand Assets".
- [x] 44. Personalización por País: Ajustar lenguaje y modismos (i18n).
- [x] 45. Programación de Publicaciones: Dejar programado contenido (Drip Feed).

## 🛡️ Nivel 3: El "Toque Humano" y E-E-A-T (Control de Calidad)
*Lo que diferencia tu contenido del spam y genera confianza.*

- [x] 46. Factor E-E-A-T: Experience, Expertise, Authoritativeness, Trustworthiness.
- [x] 47. Caja de Autor: Añadir siempre caja de autor con foto y biografía.
- [x] 48. Perfiles Reales: Enlazar autor a LinkedIn o Twitter real.
- [ ] 49. Revisor Humano (Fact-Checker): Añadir "Revisado por [Experto]".
- [x] 50. Opinión Personal: Insertar "En mi opinión..." o "Mi experiencia...".
- [ ] 51. Transparencia de IA: (Opcional) Declarar uso de herramientas de asistencia.
- [ ] 52. Divulgación de Afiliados: Poner disclaimer de afiliados si aplica.
- [x] 53. Edición Humana Ligera: Corregir alucinaciones obvias.
- [ ] 54. Imágenes Propias: Subir fotos reales tomadas por ti.
- [x] 55. Datos Actualizados: Verificar fechas y precios (Fecha de actualización dinámica).
- [x] 56. Enlaces Rotos: Revisar enlaces externos.
- [x] 57. Estilo de Marca: Diseño del blog transmite profesionalismo.
- [x] 58. Página de "Sobre Nosotros": Página sólida explicando misión.
- [ ] 59. Página de "Política Editorial": Explicar creación y revisión de contenido.
- [x] 60. Información de Contacto: Dirección o email visible.
- [x] 61. Velocidad de Carga: Optimizar imágenes (WebP).
- [x] 62. UX Móvil: Verificar tablas y visuales en celular.
- [x] 63. Evitar Palabras "AI": Limpiar muletillas típicas ("En el mundo digital...").
- [x] 64. Validar Intención: ¿Responde la duda mejor que la competencia?
- [ ] 65. Comentarios: Habilitar y moderar comentarios.

## 🚀 Nivel 4: Off-Page, Técnico y Negocio (Escalamiento)
*Link building, ventas y mantenimiento a largo plazo.*

- [x] 66. Los 3 Pilares: On-Page, Técnico y Off-Page.
- [ ] 67. Link Building (Calidad): Priorizar calidad sobre cantidad.
- [ ] 68. Estrategia "Copycat": Replicar enlaces de competencia.
- [ ] 69. Guest Posting: Ofrecer escribir para otros blogs.
- [ ] 70. Directorios: Dar de alta el sitio en directorios.
- [ ] 71. Notas de Prensa: Redactar y distribuir comunicados.
- [ ] 72. Comprar Enlaces (Con cuidado): Adquirir enlaces vetted.
- [ ] 73. Indexación Forzada: Usar API de Indexación de Google.
- [x] 74. Auditoría Técnica: Revisar 404, redirecciones y rastreo.
- [x] 75. Schema Markup: Implementar datos estructurados (Review, Article, FAQ).
- [ ] 76. Estrategia de Retención de Clientes (Agencias): Enfocarse en ROI.
- [ ] 77. Oferta Irresistible: Crear oferta "No Brainer".
- [ ] 78. Cold Calling/Emailing: Contactar negocios masivamente.
- [ ] 79. Nichos de "Dinero": Ir a clientes grandes.
- [x] 80. Venta de Resultados: Enfocarse en Leads/Ventas.
- [ ] 81. Reportes Automatizados: Configurar reportes mensuales.
- [x] 82. Diversificación de Ingresos: No depender solo de una fuente.
- [x] 83. Crear "Activos": Ver el sitio como activo digital.
- [ ] 84. YouTube SEO: Usar IA para traducir/doblar videos.
- [ ] 85. Repurposing: Convertir blog en guiones de video.
- [x] 86. Análisis de Tendencias: Usar Google Trends.
- [x] 87. Actualización de Algoritmos: Estar atento a Core Updates.
- [ ] 88. Limpieza de Contenido: Borrar/fusionar lo que no rankea.
- [x] 89. Interlinking "Hub & Spoke": Artículo pilar + satélites.
- [ ] 90. Uso de "Brand Assets": Subir PDFs propios a la IA.
- [ ] 91. Sindicación en Web 2.0: Publicar en Medium/LinkedIn Pulse.
- [ ] 92. Monitorización de Palabras Clave: Rastrear posiciones.
- [x] 93. Velocidad de Implementación: Publicar rápido.
- [x] 94. Paciencia Estratégica: Entender el Sandbox.
- [x] 95. Ética: No difamar ni fake news.
- [x] 96. Formación Continua: Mantenerse actualizado.
- [x] 97. Delegación: Automatizar/delegar IA.
- [x] 98. Backup: Copias de seguridad del sitio (Git/Vercel).
- [x] 99. Escalar Horizontalmente: Clonar sistema para otros nichos.
- [x] 100. Consistencia: Constancia en publicación y mejora.
