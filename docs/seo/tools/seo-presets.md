# Presets para seo:new

Presets disponibles:
- `ecommerce-belleza`
  - Pasos: recordatorio, reposición, última llamada
  - Prompts: asuntos reposición, copy con beneficio, timing por producto
  - FAQ: timing y asunto efectivos
- `saas-seguridad`
  - Pasos: educación, valor, activación
  - Prompts: riesgo educativo, caso de uso, activación
- `educacion`
  - Pasos: objetivos, metodología, revisión
  - Prompts: objetivos, metodología, revisión
  - FAQ: objetivos medibles, organización de revisión
 - `moda`
   - Pasos: bienvenida, carrito con urgencia suave, recomendaciones
   - Prompts: asuntos carrito moda, bienvenida con beneficio, recomendaciones
 - `moda-hombres`
   - Pasos: bienvenida, carrito con beneficio, recomendaciones por estilo
   - Prompts: asuntos moda masculina, bienvenida con oferta, recomendaciones
 - `ciso-secops`
   - Pasos: riesgo operativo, caso por equipo, activación
   - Prompts: riesgo SecOps, caso, activación
- `ciso-finanzas`
  - Pasos: riesgo regulatorio/fraude, caso financiero, activación
  - Prompts: riesgo CISO finanzas, métrica financiera, activación
 - `moda-accesorios`
   - Pasos: bienvenida con oferta, carrito accesorios, recomendaciones por ocasión
   - Prompts: asuntos carrito accesorios, bienvenida con oferta, recomendaciones
- `ciso-healthcare`
  - Pasos: riesgo regulatorio (HIPAA), caso en clínica/hospital, activación
  - Prompts: riesgo CISO healthcare, métrica (incidentes/tiempo), activación
- `moda-zapatos`
  - Pasos: bienvenida con oferta limitada, carrito zapatos, recomendaciones por temporada
  - Prompts: asuntos carrito zapatos, bienvenida con oferta, recomendaciones por temporada
- `ciso-saas-fintech`
  - Pasos: riesgo en SaaS fintech, caso con métrica financiera, activación de módulo
  - Prompts: riesgo CISO SaaS fintech, métrica (fraude/MTTR), activación
- `moda-zapatos-deportivos`
  - Pasos: bienvenida con oferta calzado deportivo, carrito deportes, recomendaciones por actividad
  - Prompts: asuntos carrito calzado deportivo, bienvenida con oferta, recomendaciones por actividad
- `ciso-saas-pagos`
  - Pasos: riesgo en pasarelas de pago, caso con métrica (rechazos/fraude), activación de módulo
  - Prompts: riesgo CISO SaaS pagos, métrica financiera (fraude/chargeback/MTTR), activación
 - `moda-zapatos-deportivos-mujer`
   - Pasos: bienvenida con oferta deportiva mujer, carrito deportes mujer, recomendaciones por actividad/estilo
   - Prompts: asuntos carrito calzado deportivo mujer, bienvenida con oferta, recomendaciones por actividad/estilo
 - `ciso-saas-pagos-latam`
   - Pasos: riesgo en pagos LATAM, caso con métrica financiera LATAM, activación
   - Prompts: riesgo CISO SaaS pagos LATAM, métrica (fraude/chargeback/MTTR), activación regional

Uso:
- `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=ecommerce-belleza`
- `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=moda-accesorios`
- `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=ciso-healthcare`
- `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=moda-zapatos`
- `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=ciso-saas-fintech`
- `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=moda-zapatos-deportivos`
- `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=ciso-saas-pagos`
 - `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=moda-zapatos-deportivos-mujer`
 - `npm run seo:new -- --id=slug --title="Titulo" --desc="Resumen" --tags=tag1,tag2 --preset=ciso-saas-pagos-latam`
