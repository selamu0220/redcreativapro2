# SEO Suggest — Títulos y Meta

Comando:
- `npm run seo:suggest`

Salida:
- Genera `docs/seo/analytics/title-suggestions.md` con 3 variantes de título y 3 de meta por post.

Uso recomendado:
- Revisa CTR en GA y actualiza título/meta del artículo si el CTR es bajo.
- Prioriza beneficios, números y claridad en español.
