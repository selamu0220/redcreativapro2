# 🚀 SEO Checklist Maestro: Estrategia de Crecimiento 2026

Este documento contiene la hoja de ruta crítica para el posicionamiento orgánico, dividida en niveles de ejecución.

---

## 🔴 Nivel 1: Fundamentos Críticos y Configuración (Lo imprescindible)
*Estas tareas deben completarse antes de crear contenido.*

- [x] Definir el objetivo principal del sitio web (venta, leads, tráfico).
- [x] Instalar Google Analytics 4 (GA4).
- [x] Configurar Google Search Console (GSC).
- [x] Verificar la propiedad del dominio en GSC.
- [x] Crear un archivo `robots.txt` básico.
- [x] Asegurarse de que `robots.txt` no esté bloqueando a los bots de Google.
- [x] Generar un Sitemap XML (usando plugin o manual).
- [x] Enviar el Sitemap XML a Google Search Console.
- [x] Instalar un plugin de SEO (Yoast, RankMath, etc., si aplica) *(Usando Next.js Metadata API)*.
- [x] Configurar la estructura de permalinks (URLs amigables).
- [x] Asegurar que el sitio tenga certificado SSL (HTTPS activado).
- [x] Verificar que el sitio sea "Mobile-Friendly".
- [x] Crear la página de **Contacto**.
- [x] Crear la página de **Política de Privacidad**.
- [x] Crear la página de **Términos y Condiciones**.
- [x] Definir la arquitectura básica del sitio (Home > Categorías > Posts).
- [x] Asegurar que ninguna página importante esté a más de 3 clics de la Home.
- [x] Comprobar la velocidad de carga en Google PageSpeed Insights.
- [ ] Identificar a los 3 competidores principales en el nicho.
- [x] Entender la diferencia entre SEO On-Page y Off-Page.

---

## 🟠 Nivel 2: Investigación y Estrategia de Contenidos (El Core)
*Aplicar la "Lista de Verificación de 5 Puntos" para cada tema.*

- [x] Realizar una lluvia de ideas de temas "semilla".
- [x] Usar herramientas de palabras clave (Ahrefs, Ubersuggest, GKP) para expandir ideas.
- [ ] **Validación 1 - Demanda:** Filtrar KWs con volumen de búsqueda > 0.
- [ ] **Validación 2 - Tráfico:** Revisar el tráfico total de la página #1 en Google.
- [ ] **Validación 3 - Negocio:** Puntuar cada KW (1 al 3) según potencial de venta.
- [ ] Descartar KWs con puntaje "1" si el sitio es nuevo.
- [ ] **Validación 4 - Intención:** Analizar el SERP (Tipo, Formato y Ángulo de contenido).
- [ ] **Validación 5 - Dificultad:** Revisar DR y backlinks del Top 10.
- [x] Seleccionar una "Palabra Clave Objetivo" principal por página.
- [x] Listar palabras clave secundarias (LSI) o variaciones long-tail.
- [x] Crear un calendario editorial con fechas de publicación.
- [x] Asignar una intención de búsqueda clara a cada entrada.
- [x] Definir el slug (URL) corto y con la KW antes de escribir.
- [ ] Analizar las PAA (People Also Asked) en Google.
- [ ] Definir la extensión estimada basada en la competencia.

---

## 🟡 Nivel 3: Ejecución On-Page y Redacción (La Creación)
*Satisfacer la intención del usuario mejor que la competencia.*

- [x] Escribir un Título H1 que incluya la palabra clave principal.
- [x] Escribir un Meta Title atractivo (CTR) bajo 60 caracteres.
- [x] Redactar una Meta Descripción con CTA bajo 160 caracteres.
- [x] Usar la palabra clave en el primer párrafo.
- [x] Estructurar con subtítulos H2 y H3 lógicos e inclusivos de KWs.
- [x] Escribir párrafos cortos (máximo 3-4 líneas).
- [x] Usar viñetas (bullet points) y listas.
- [x] Responder a la pregunta del usuario inmediatamente (Below the fold).
- [x] Renombrar archivos de imagen antes de subir (ej: `seo-tecnico.jpg`).
- [x] Comprimir imágenes (WebP/JPG optimizado).
- [x] Añadir Texto Alternativo (ALT Text) descriptivo.
- [x] Enlazar internamente a otros artículos relevantes.
- [x] Usar "anchor text" descriptivo.
- [x] Enlazar externamente a fuentes de autoridad (abrir en pestaña nueva).
- [x] Incrustar videos de YouTube si aportan valor.
- [x] Revisar ortografía y gramática meticulosamente.
- [x] Añadir Tabla de Contenidos (índice) si el artículo es largo.
- [x] Incluir una conclusión y una llamada a la acción (CTA) clara.

---

## 🔵 Nivel 4: Autoridad (Off-Page) y Mantenimiento (El Crecimiento)
*Conseguir votos de confianza y mantener la salud del sitio.*

### Link Building
- [ ] Registrarse en plataformas como HARO para menciones de expertos.
- [ ] Responder solicitudes de periodistas aportando valor real.
- [ ] **Guest Posting:** Listar 10 blogs del nicho y enviar propuestas únicas.
- [ ] Incluir enlaces contextuales hacia nuestro sitio en guest posts.
- [ ] **Estrategia Skyscraper:** Mejorar contenido viral y contactar a quienes enlazan al original.

### Distribución y Técnico
- [ ] Compartir cada post en redes sociales y comunidades (Reddit, Quora).
- [x] **Auditoría Semanal:** Revisar errores 404 en Search Console.
- [x] Configurar redirecciones 301 para enlaces rotos.
- [x] Eliminar "Páginas Huérfanas" enlazándolas internamente.
- [x] Optimizar Core Web Vitals (LCP < 2.5s, CLS bajo).
- [x] Actualizar contenido antiguo cada 6-12 meses (refresh de títulos).
- [x] Verificar y corregir canibalización de palabras clave.

### Estrategia Local (Si aplica)
- [ ] Conseguir enlaces de directorios locales.
- [ ] Crear y optimizar perfil de Google My Business.
- [ ] Solicitar reseñas a clientes satisfechos.

---
**Protocolo:** Investigar > Crear > Optimizar > Enlazar > Repetir.
